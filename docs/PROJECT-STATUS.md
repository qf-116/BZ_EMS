# 项目状态与需求范围（唯一权威文档）

> 更新：2026-09-16 ｜ 本文档是当前需求范围与项目进度的**唯一权威来源**。
> 历史设计/需求文档已归档至 `docs/archive/`，其中的范围结论（尤其旧设计方案 §0.3/§7.3）**已过时，不得作为删除功能的依据**。

## 1. 项目定位

- 东浩智创设备管理系统**标准版·前端演示**：React 19 + Ant Design 6 + Vite 7，无真实后端/IoT/鉴权，全部为演示数据驱动。
- 交付形态：单文件 `dist/index.html`（可双击 file:// 打开）；开发入口为根目录 `dev.html`（构建后自动改名为 dist/index.html，见 vite.config.js）。
- 演示基准时间：2026-09-16 16:41:08（+08:00），每次动作推进 7 秒，全程可重放、可重置。

## 2. 需求范围（当前有效，勿再裁剪）

### 2.1 核心业务域（DemoStore 状态机驱动，动作幂等、跨页同步）

1. 工作台（待办/异常汇总 + 重置演示）
2. 设备资产：台账 / 详情 / 文档库 / 基础类型配置
3. 数据接入：联网配置总览（绑定状态机） / 平台指标清单 / 程序参数比对 / 比对处理记录
4. 运行监测：监测总览 / 实时监控（数据源模式切换） / 设备监测详情
5. OEE：实时 / 历史 / 日明细 / 理想速度配置 / 计划停机（公式实时推导，保存即重算可见）
6. 报警中心：触发→确认→处理→恢复→关闭全状态机 + 规则版本 / 通知策略（只读）
7. 维修：报修 / 派工 / 执行 / 验收 / 返修（工单 param 路由，联动停机与报警）
8. 备件：台账 / 入库 / 出库（关联工单 + requestId 幂等）/ 退库 / 流水
9. 报表中心：运行/产量/MTTR·MTBF/综合/报警/质量/程序比对/维修/备件 9 张 + 导出任务
10. 监测大屏：`/screen/device` 独立深色大屏（React 渲染，非 iframe）

### 2.2 点检 / 保养 / 巡检 —— **演示模块，必须保留** ⚠️

- 该三模块曾被旧设计方案（§0.3"明确不做"）判定为范围外而移除，**需求方已明确要求恢复并永久保留**。任何后续"范围收敛/优化"迭代不得再删除其页面、菜单、路由或需求细则。
- 定位：范围外演示模块。数据只读来自 `src/data/standardData.js` 种子，设备经 `src/data/demo/deviceCrosswalk.js` canonical 映射；新增/编辑/执行为页面本地 UI 演示交互（明确提示不落库），完整业务闭环由点巡保养业务模块承接。
- 页面共 27 个（每域 8 页 + 1 报表）：`/inspection-*`、`/maintenance-*`、`/patrol-*`、`/report/inspection|patrol|maintenance`。

### 2.3 明确由宿主平台承接（保留 ScopeNoticePage，勿开发）

- 权限管理 `/permissions`、操作审计 `/audit`：平台基础管理模块提供。
- 真实后端 / WebSocket / MQTT / 协议 / 网关 / IP / 端口 / 点表编辑：不在前端演示范围。

## 3. 架构要点（改代码前必读）

- 状态层（**禁止页面绕过**）：`src/state/DemoStore.jsx`（Provider + localStorage `dms-demo:state`，STORE_VERSION=3）+ `reducer.js`（动作白名单/幂等登记/演示时钟）+ `actions.js`（前置校验，返回 `{ok,message,refs}`）+ `selectors.js`（所有读模型）+ `persistence.js`。
- 领域规则：`src/domain/{binding,alarm,repair,spare,downtime,oee}.js`（状态机 + 校验）。
- 演示数据：`src/data/demo/*`（8 台设备 DEV-001..008，canonical 映射见 deviceCrosswalk.js——台账 assetCode ↔ 监测编码 ↔ OEE，历史上三套数据冲突已按此文件头注释裁决）。
- 兼容种子：`src/data/standardData.js`（点巡检保养 + 规则/文档库等旧页面用）、`src/data/demoData.js`（报表行 + 规则页用）。
- 硬口径：空值/null/未配置 一律 `--`（≠ 0）；sourceTime 管统计归属、receiveTime 只管延迟；canonical deviceId 唯一；`meta.lastAction` 为动作结果位置。
- 三个演示剧本：A=DEV-004 故障闭环（报警→…→验收→恢复关闭）、B=DEV-002 延迟+程序比对、C=DEV-005 离线无数据显示 `--`。
