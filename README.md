# 东浩智创 设备管理系统标准版

纯前端独立演示系统（React + Ant Design + Vite），无需任何后端服务器，全部为内置演示数据。
整合原监测后台与设备管理标准功能，每个功能均为独立页面（无 Tab 切换页），按业务域分组导航。

## 打开方式

> **整个工程只有一个 `index.html`，即交付产物 `dist/index.html`**。开发入口已改名为 `dev.html`，仅供 `npm run dev` 使用，请勿双击打开。

- **直接双击 `dist/index.html`**（推荐，单文件构建，无需服务器，拷贝到其他电脑也可打开）
- 开发调试：`npm install` 后运行 `npm run dev`（自动打开 `http://localhost:5173/dev.html`）

登录页演示账号：`admin / 123456`，或点击「一键演示登录」。

## 原型一致性说明

设备台账、点检、巡检、保养、维修、备品备件六大模块已按客户 Axure 原型 HTML 逐页移植：

- 列表页的**查询条件、列表字段、工具栏按钮**（新增/导入/启用/禁用/打印二维码/指派任务等）与原型一一对应；
- **新增/编辑、详情、执行类页面**（如新增设备档案、点检标准详情、添加点检计划、执行点检、执行保养、执行故障维修、到货入库、领用出库等）均按原型表单字段实现；
- **交互约定**：所有模块的**新增/编辑均为列表页内弹窗（Modal）**；**详情页与执行页为独立路由页面**（如各模块 `…/detail`、`…/execute`），从列表"详情/开始执行"跳转进入；
- 维修任务来源区分报修任务 / 监测异常 / 快速维修；保养计划区分保养年度 / 保养层级 / 保养方式（单次保养、循环保养）；备件现存量按多仓库存总和口径展示。

## 约定

- **每个功能独立页面、独立路由、独立菜单项**，不使用页面内 Tab 切换；
  同一业务的多个页面归入对应一级菜单（如点检项目/标准/计划/任务归入「点检管理」）。
- 新增全生命周期功能（采购→验收等）时：在 `src/pages/` 新增页面组件，
  在 `App.jsx` 的「设备资产」菜单组中登记菜单与路由即可。
- 报表页复用 `src/components/ReportFilter.jsx` 通用筛选条。

## 演示数据维护

监测侧数据见 `src/data/demoData.js`，设备管理业务数据见 `src/data/standardData.js`。
后续接入真实后端时，按页面组件内的数据结构定义接口返回即可。
